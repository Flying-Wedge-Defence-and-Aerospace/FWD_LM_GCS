Product Overview

Functions:
FWDGCS provides functionalities including flight control, aircraft configuration, UAV data monitoring, mission planning, camera operation, video transmission, and login authentication.

Applications:

  • Flight control and operation
  • Mission planning and execution
  • Data exchange and processing
  • System monitoring and maintenance

Supported UAV Types:

  • Multirotor UAVs
  • Fixed-wing UAVs
  • VTOL Fixed-wing UAVs
  • Ground vehicles
  • Watercraft

Product Description

Purpose of the Software:
Flight control and mission execution. Data visualization and decision support.

Core Features:

  • Flight control
  • Mission management and payload control
  • Data exchange and processing
  • System maintenance and diagnostics
  • Login authentication and session management
  • Enhanced video streaming with custom controls

Supported Platform:
Windows 10/11, Ubuntu 20.04/22.04, Android 8.0+

What Makes FWDGCS Different:
FWDGCS extends standard QGC with a custom login/authentication system, enhanced video controls, FWD branding (deep red theme #700000, FWD logo), and Navy-specific pre-configurations.

Installation Steps

Windows Installation

  1. Download the FWDGCS installer (FWD_NAVY_GCS-x.x.x-installer.exe) from the FWD distribution portal
  2. Run the installer as Administrator
  3. Follow the setup wizard — accept the license, choose installation directory (default: C:\Program Files\FWDGCS), select components
  4. Click Install
  5. Launch FWDGCS from the Start Menu or desktop shortcut
Note: If video is not working, install GStreamer 1.18.6 runtime separately. Configure Windows Firewall to allow FWDGCS for MAVLink UDP/TCP ports.

Linux Installation

  1. Download the AppImage: FWD_NAVY_GCS-x.x.x-x86_64.AppImage
  2. Make it executable: chmod +x FWD_NAVY_GCS-x.x.x-x86_64.AppImage
  3. Run: ./FWD_NAVY_GCS-x.x.x-x86_64.AppImage

Android Installation

  1. Download the APK: FWD_NAVY_GCS-vx.x.x.apk
  2. Enable Install from Unknown Sources in Settings > Security
  3. Open the APK file and follow installation prompts
  4. Grant permissions: Location, Storage, USB

Quick Start

Main Interface Overview

Upon successful login, the main interface is displayed containing the toolbar, status bar, and view selector. The main views are: Fly, Plan, Setup, and Analyze.

Flight Information

The status bar displays GPS status, battery voltage, telemetry signal strength (RSSI), flight mode, and armed status.

[Screenshot: Main Interface Overview]

Quick Start Example

The following is an example of video output, drone connection, and quick takeoff.

Camera Output

Step 1: Tap the three dots in the top-right corner.

Step 2: Select the Camera Module.

Step 3: Tap the downward triangle in the camera address bar and select the correct camera address. Alternatively, tap the pencil icon to manually enter the camera address as prompted.

Data Link Connection

Step 1: Tap the three dots in the top-right corner.

Step 2: Set Data Link to UDP, and set the baud rate to 57600 (ensure it matches the baud rate set in the flight controller).

Step 3: Set the connection type, then click Connect. Enter the address as prompted and click Confirm to establish the connection.

Shortcut Buttons

One-Touch Takeoff: Tap the one-touch takeoff button, then press and hold as prompted. The drone will climb to 10 meters and hover.

One-Touch Landing: Tap the one-touch landing button, and the drone will land at its current position.

One-Touch Return: Tap the one-touch return button, and the drone will climb to the return altitude and fly back to the takeoff point.

[Screenshot: Quick start buttons]

Core Function Instructions

The core functions include: Login Module, Fly View Module, Video System Module, Mission Planning Module, and Vehicle Setup Module.

Login Module

Login Screen Overview

When FWDGCS starts, the login screen is displayed. Features include:

  • FWD Logo displayed prominently at the top
  • Title: "GROUND CONTROL STATION" with "FWDGCS" subtitle
  • Red gradient theme (#700000)
  • Login form with username, password, Remember Me checkbox, and Login button
  • Register link to toggle to registration form
[Screenshot: Login Screen]

Login Procedure

  1. Enter your Username and Password
  2. Check Remember Me to retain credentials on this device
  3. Click Login
  4. On successful authentication, the main application window loads

Registration

If you do not have an account, click the Register link and fill in the required fields: Full Name, Username, Email Address, Password, Confirm Password. Click Register to submit.

Note: Registration functionality may require server-side setup. Contact your system administrator if registration is unavailable.

Session Management

  • Your session remains active until you log out or close the application
  • Remember Me stores a token locally for automatic login on subsequent launches
  • Sessions have a configurable timeout period after which re-authentication is required

Logout

  1. Click the profile icon on the main toolbar
  2. Select Log Out
  3. Confirm the action when prompted
  4. The application checks for active vehicle connections before logging out
  5. You are returned to the login screen
Danger: Ensure your vehicle is safely landed and disarmed before logging out, as the connection will be terminated.

Accelerometer Menu

Displays accelerometer data and IMU temperature. Provides options for accelerometer calibration and flight controller levelling.

Accelerometer Calibration: Follow instructions to place the drone in six orientations as shown. After completion, restart the drone.

Horizontal Calibration: Place the drone on a flat, level surface and ensure it remains still. Click Horizontal Calibration.

[Screenshot: Accelerometer calibration]

Compass Menu

Do not calibrate in areas with strong magnetic fields or near large metal objects. Avoid carrying ferromagnetic materials during calibration.

Steps:

  1. Open the compass calibration interface
  2. Click Calibrate
  3. Lift the drone and rotate in different directions — ensure each side (front, back, left, right, top, bottom) points downward for a few seconds
  4. Restart the drone
[Screenshot: Compass calibration]

Remote Control Calibration

Stick Centering: Before calibration, ensure all sticks are centred, confirm correct polarity, then click Calibrate.

Safety Tips: Remove all propellers before calibration. Click Confirm.

Channel Data Logging: Gradually move joysticks and switches to their maximum and minimum positions in sequence.

Calibration Complete: Click Complete to finish. The software displays recorded maximum and minimum values for each channel.

Parameter Table

Includes functions for importing, exporting, searching, modifying, refreshing, resetting, and rebooting the flight controller.

Parameter Search: Enter the parameter name and click search.

Parameter Modification: Double-check parameters before modification. Enter the desired value and click Write.

Parameter Export: Click Export Parameters to save all parameters to the remote controller.

Parameter Import: Click Import Parameters and follow prompts to import parameters to the flight controller.

Parameter Reset: Click Reset to restore all parameters to default settings.

Flight Controller Restart: Click Restart Flight Controller to remotely reboot. Must be in unlocked state.

Mission Planning Module

Main Menu of the Waypoint Module

  • View and Plan Waypoints: View waypoint library, plan standard and mapping missions
  • Start/Pause Mission: Start mission execution. During execution, click to pause (multirotor hovers, fixed-wing loiters, rover holds). Click again to resume
  • Clear Mission: Clears mission from interface and flight controller. Confirmation required during execution
  • Exit Mission: Exit current mission (multirotor hovers, fixed-wing loiters, rover holds)
  • Download Mission: Download mission stored in flight controller
  • Locate Aircraft: Centre aircraft on map
  • Map Type: Switch between street and satellite map
[Screenshot: Waypoint module main menu]

Mission Library

Stores planned and saved missions for easy viewing and modification.

Waypoint Mission

Each waypoint's location must be manually selected. Altitude, speed, and action can be adjusted. The completion action can also be modified.

Create Mission

Click Mission Planning button, select Create Waypoint Mission.

Waypoint Flight

Assign a name to the mission. Supports switching altitude modes:

  • Absolute Altitude: Height relative to mean sea level (MSL)
  • Relative Altitude: Height relative to takeoff point

Route Settings

  • Safe Takeoff Altitude: Altitude to reach before first waypoint
  • Speed: Horizontal speed during waypoint flight
  • Route Altitude: Flight altitude during mission
  • Completion Action: Return to Home, Landing, or Hover

Waypoint Settings

  • Speed: Flying speed after reaching waypoint
  • Height: Required altitude before reaching waypoint
  • Waypoint Action: Actions executed after reaching waypoint
  • Hover: Hover at waypoint for set duration
  • Latitude/Longitude Fine-tuning

Task Execution

  1. After planning, click Save
  2. Click Start to upload flight route
  3. Confirm flight checklist
  4. Check route information (speed, altitude range, completion actions)
  5. Wait for route upload to complete
  6. Unlock the drone and click Execute Task
[Screenshot: Waypoint mission planning]

Jump to Current

Click a specific waypoint, then click Jump to Current. The drone flies directly to the selected waypoint.

Note: If clicking has no effect, download the flight route first, then select a waypoint to execute the jump action.

Mapping Route

Route Planning

Mapping Route Settings

  • Select Camera: Choose camera for mapping tasks
  • GSD: Ground Sample Distance
  • Altitude Mode: Absolute or Relative
  • Route Speed/Height
  • Completion Action
  • Advanced Settings: Heading overlap, sidelap, external margin

  • GPS Lock — sufficient satellites and 3D fix
  • Battery Voltage — within acceptable range
  • Accelerometer — calibration valid
  • Magnetometer — calibration valid
  • Gyroscope — calibration valid
  • RC Signal — valid signal received
  • Throttle — at minimum

Troubleshooting

Common Errors

Unable to Connect to Data Link

  1. Ensure the air unit is properly connected to your flight controller
  2. Check wiring: TX/RX properly crossed? Data Link configuration correct?
  3. In the app, check Link Information — Data Link Downlink should be > 0
  4. Check Data Transmission Settings: connection method and baud rate correct?
  5. Try switching data cable to TELEM 1 or TELEM 2 port
  6. Are both ground station and sky end running latest firmware?
  7. If using wireless hotspot for UDP, disable computer Ethernet

Unable to Display Image

  1. Check connection: Ground and sky end properly synced (green status indicator)? Camera correctly connected to sky end?
  2. Check software settings: Camera address field correctly set in app?
  3. Check network: If using handheld ground station, is Ethernet enabled in Android system settings?
